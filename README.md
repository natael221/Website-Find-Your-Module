# 🔍 Find Your Module - UI Project

A clean and minimal web-based UI to help participants explore and access learning modules provided during the **Kampus Merdeka - MSIB** program.

---

## 🎓 Background

This project is the final UI assignment from my participation in the **Kampus Merdeka - MSIB (Magang dan Studi Independen Bersertifikat)** program, held by **TIMCorp-Academy** in **Semester 5 (2023)**.
I took part in this program under the **AWS Cloud Solution Architect** track.

---

## 🖥️ About the Project

**Find Your Module** is a user-friendly website designed to simplify the discovery of learning modules and program materials. It aims to help MSIB participants find resources by category through a static and structured UI layout.

### 🔧 Features

* 📚 Clean navigation between module categories
* 👤 Pages for registration, email verification, and user profile
* 📄 Multiple learning module pages (e.g., Cloud, Programming, Design)
* 🧩 Fully static layout, easily extendable with backend or CMS
